# Tic-Tac-Toe Game

🎮 **Play it live:** https://mdfarhanu389-oss.github.io/tic-tac-toe-game/

![Game screenshot](screenshot.png)

A two-player Tic-Tac-Toe game where players take turns placing X and O
on a 3x3 grid. The game detects the winner automatically.

## Features
- Two-player gameplay (X and O)
- Winner detection with a message
- New Game and Reset Game buttons

## Built With
- HTML
- CSS
- JavaScript

## How to Run
1. Download or clone this repository
2. Open `index.html` in your browser
